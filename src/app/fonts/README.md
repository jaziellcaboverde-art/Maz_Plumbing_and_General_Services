Inter is self-hosted with `next/font/local` so builds do not require a Google Fonts download. `Inter-latin.woff2` is the Latin variable font already used by this application's Google-font loader, copied from its existing local development asset. The configured normal 400–600 weight range and system fallbacks are preserved.
