Public Sans is self-hosted with `next/font/local` and applied in the root layout across the public site, admin, customer and provider pages. Normal and italic variable files support weights 100–900. Headings, controls and tables inherit the same family; the existing font-size accessibility settings still apply.

Source: https://github.com/google/fonts/tree/main/ofl/publicsans . The SIL Open Font License is included as `PublicSans-OFL.txt`. Builds and visitors do not need a Google Fonts request.

The previous `Inter-latin.woff2` asset is retained as an unused reference. Its original license is in `OFL.txt`.
